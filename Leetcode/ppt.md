## P4 转折页：技术中立是个幻觉

**【幻灯片上写】**
- 大标题：代码没有价值观，但——
- 三行递进（逐行放大字号）：
  - 写代码的人，有老板；
  - 老板，有KPI；
  - KPI背后，是资本。
- 底部原理框：马克思：社会存在决定社会意识——任何观念与技术，都从具体的物质生产中生长出来，没有悬浮的"中立"。
- 右下角一句：所以今天不批判技术，批判技术背后的**生产关系**。

**【你口头讲】**
> "技术圈流行一句话：'技术是中立的，代码没有价值观。'我信过。但马克思告诉我们，社会存在决定社会意识——算法从来不是悬浮的：数据从哪来？目标谁定的？KPI是什么？答案都指向资本。所以我们批判的不是技术，而是它背后的生产关系。"

## P5 概念一：文化霸权（葛兰西）

**【幻灯片上写】**
- 定义：现代统治不靠强制，靠**同意**——让你觉得一切都是你自己的选择。（葛兰西）
- 对比表：
  | | 旧意识形态机器 | 算法平台 |
  |---|---|---|
  | 主体 | 学校 / 教会 / 报纸 | 推荐算法 |
  | 方式 | 告诉你什么是对的 | 决定你能看到什么 |
  | 你的感受 | "我在被教育" | "我在自由选择" |
- 核心逻辑：算法不需要有自己的观点，只需要**控制分发的入口**。
- 页脚金句：最高明的灌输，是让你感觉不到灌输的存在。

**【你口头讲】**
> "过去塑造价值观的是学校、报纸，你清楚地知道'这是教育'。而算法不告诉你什么对，它只是安静决定你看得到什么、看不到什么。被喂了三个月某种内容后，某天你'自然而然'地认同某个观点——观点是你的，但原材料是算法筛选过的。这就是算法时代的文化霸权。"

## P6 概念二：无偿数字劳动

**【幻灯片上写】**
- 标题：你以为在娱乐，其实在上班
- 马克思原话：劳动是价值的唯一源泉。——《资本论》
- 流水线图：
  - 你刷手机（点赞/停留/划走）→ 生产**行为数据**
  - 行为数据 → 加工为**精准用户画像** → 卖给广告商
  - 平台获得利润 → **你的收益：0元**
- 三个等式（冲击性排版）：
  - 1个赞 = 1次免费的内容质量评估
  - 1秒停留 = 1次免费的画像校准
  - 全球最大规模的数据标注团队 = 十亿无偿的用户
- 页脚：数字时代的剩余价值，不只来自工厂，也来自你的沙发和床。——你的休闲时间，是谁的生产资料？

**【你口头讲】**
> "劳动价值论说价值由劳动创造。你刷视频时创造价值吗？看这条流水线：你的每个动作都是免费的标注劳动，被加工成画像卖给广告商，利润归平台——这就是数字时代的剩余价值。顺便问一句：今天刷过手机的同学，你们已经无偿上过班了。"

## P7 概念三：异化 · 信息茧房 · 单向度的人

**【幻灯片上写】**
- 三张卡片：
  1. **劳动异化**（马克思）：人创造了自己的创造物，然后被它支配——你训练算法，算法反过来塑造你。
  2. **信息茧房**（桑斯坦，2006）：你只看到你"想看的"，最终看不到世界本来的样子。马原视角：茧房不是技术的必然，而是**资本逻辑的必然**——舒适的内容才有时长和流量。
  3. **单向度的人**（马尔库塞）：舒适的投喂钝化反思能力，"爽"取代了"思考"。
- 底部闭环图：**越焦虑 → 越刷 → 越推送焦虑 → 越焦虑**。你的痛苦，在为平台贡献时长。

**【你口头讲】**
> "马克思的异化：工人创造机器反被机器支配，今天我们喂养算法，算法反过来支配视野。茧房在马克思主义视角下不是技术必然——而是资本逻辑必然，因为让你舒服停留的内容才有流量。最后变成闭环：越焦虑越刷，越刷越推送让你焦虑的内容。"

## P8 案例：流量为什么偏爱对立？

**【幻灯片上写】**
- 闭环图：
  - 对立话题 → 情绪激烈 → 评论互撕 → 互动率飙升 → 算法判定"高价值" → 更大推荐权重 → 更多对立内容 →（回到起点）
- 两行点题：
  - 资本的天职是增殖——这条定律如今运行在代码里，全自动、无人值守。
  - 没有人需要为撕裂负责，因为"这是算法的决定"。这才是最可怕的地方。

**【你口头讲】**
> "为什么热搜永远是对立？不是算法邪恶，算法只是忠实执行'什么有互动就推什么'。对立永远比共识有互动。于是一个全自动循环形成了。资本增殖的逻辑换了个载体运行在代码里——而且无人需要为此负责。"

## P10 出路：三层解方

**【幻灯片上写】**
- 三层阶梯图：
  - **个人层**：主动破茧——主动搜索、关注异质观点；看到不同意的内容，先别划走，想想算法为什么推给你。信息节食。
  - **技术层**：改写目标函数——从"优化时长"到"优化人的长期成长"；算法透明与可解释。**这是我们这代CS人欠的债，也该由我们来还。**
  - **制度层**：算法备案、平台反垄断、数据的公共属性——当数据成为关键生产资料，**"数据归谁所有"就是数字时代的所有制问题。**（生产关系必须适应生产力的发展）

**【你口头讲】**
> "怎么办？个人主动破茧；技术上，推荐系统完全可以优化'长期成长'而非'短期时长'，这需要我们去改；制度上，马克思说生产关系必须适应生产力——数据所有制就是数字时代绕不开的问题。这也是我学这门课最大的收获。"
