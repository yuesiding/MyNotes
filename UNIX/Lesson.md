# Linux 用户与权限 

## 一、UID 关键数字

| UID | 身份 |
|-----|------|
| 0 | root |
| 1–999 | 系统账号 |
| ≥1000 | 普通用户 |

## 二、必背命令

### 用户管理
```bash
useradd        # 创建用户（底层，默认不建主目录）
adduser        # 创建用户（交互式，自动配置）
userdel -r     # 删除用户 + 主目录(不带-r就不删除主目录)
usermod -aG    # 添加附加组（-a 不能忘）
usermod -d -m  # 迁移主目录
```

### 密码管理

```bash
passwd         # 改密码
passwd -l      # 锁定账号
passwd -u      # 解锁账号
```

### 组管理

```bash
groupadd       # 创建组
groupdel       # 删除组
```
### 提权

```bash
sudo           # 临时提权
visudo         # 编辑 sudoers 文件
```

### 审计

```bash
lastlog        # 最近登录
id             # 查看用户身份
sudo -l        # 查看当前用户 sudo 权限
```


## 三、关键文件
```bash
/etc/passwd 用户信息
/etc/shadow 密码哈希，仅 root 可读
/etc/group 组信息
/etc/sudoers sudo 授权配置
```

## 四、提示符
```bash
# root   $ 普通用户
```

## 五、退出方式
```bash
exit 最常用
logout 清理进程和临时文件
Ctrl+D 发送 EOF
```

## 六、易错点
```bash
usermod -aG -a 忘写会覆盖原有附加组
userdel vs userdel -r 后者连主目录一起删
useradd vs adduser 前者底层，后者交互
创建用户报“文件已存在” 删 /var/spool/mail/用户名
创建用户报“组不存在” 先 groupadd
无法登录 Shell 被设 nologin 或账号被锁
```


# Linux文件系统 & vi编辑器知识总结

## 第一部分 Linux文件系统
### 1.1 文件系统基础
文件系统是操作系统和用户交互的核心桥梁，负责文件、目录的组织、存储、访问控制。

|对象|作用|
|----|----|
|文件|数据载体，Linux采用**字符流抽象**，所有内容当做字节序列|
|目录|逻辑容器，存放文件，构成倒树型目录结构，是路径、权限的基础|

#### Linux七种文件类型
|标识|文件类型|说明|
|----|--------|----|
|`-`|标准文件|文本、程序、二进制数据|
|`d`|目录文件|维护文件名与inode映射，管理文件|
|`l`|符号链接|软链接，指向别的文件/目录，实现共享|
|`p`|管道文件|进程间单向通信|
|`c`|字符设备|键盘、串口，按字符访问外设|
|`b`|块设备|硬盘、光驱，按块访问存储设备|
|`s`|套接字|进程间、网络通信端点|

> 💡易错点：Linux一切皆文件，但不同文件类型行为完全不一样；目录也是特殊文件，不要把目录和普通文件混为一谈。

### 1.2 目录层次结构
- 整体结构：**倒树型，根目录唯一`/`，无Windows盘符概念，路径唯一，便于权限管控**。

#### 核心目录功能
|目录|用途|
|----|----|
|`/bin` & `/usr/bin`|系统常用命令，单用户模式也可使用|
|`/dev`|设备文件入口，内核驱动和用户交互|
|`/etc`|系统配置文件，各类服务配置存放点|
|`/lib` & `/usr/lib`|动态链接库|
|`/tmp`|临时文件，系统会自动清理|
|`/var`|变化的数据：日志、缓存等|
|`/home`|普通用户家目录，用户私有空间|

> 💡易错点：不要随意修改、删除`/etc`下系统配置；不要把业务大量数据放`/tmp`，会被系统清理。

### 1.3 权限模型精要
- 3类身份：**所有者u、所属组g、其他人o**
- 3种动作：读r、写w、执行x

#### 📄普通文件权限释义
|权限|含义|
|---|---|
|r|读取文件内容|
|w|修改文件内容|
|x|可以运行该程序文件|

#### 📂目录权限释义（高频易错！）
|权限|含义|
|---|---|
|r|列出目录内文件名列表|
|w|创建、删除、重命名目录内文件|
|x|**进入(cd)目录，访问目录下文件元数据**|

> ⚠️超级易错：目录**仅有r没有x**：能看到文件名，但是无法访问文件详情；目录有w没有x：无法对里面文件做增删改。访问目录必须要有x权限。

#### 权限两种表达方式
1. **字符表示法**：`rwxr-xr--`，顺序 u→g→o；示例：`chmod u+x file`
2. **数字表示法（421）**：r=4，w=2，x=1；每组相加得到0‑7，三段数字代表u g o
    - 例：`rwxr-xr--` = 7 5 4 → `754`

常用权限模板：
|数字权限|字符等价|适用场景|
|---|---|---|
|755|`rwxr‑xr‑x`|脚本、程序目录|
|644|`rw‑r‑‑r‑‑`|普通配置文本文件|
|600|`rw‑‑‑‑‑‑‑`|密钥、敏感配置|
|700|`rwx‑‑‑‑‑‑`|私有用户目录|

### 1.4 权限查看与修改命令
1. **ls -l**：查看文件权限、属主属组；输出第1字符代表文件类型，之后9位为ugo权限。
2. **chown** 修改所有者/属组
```bash
chown user:group filename    #同时修改属主、属组
chown user filename          #仅修改所有者
chown -R user:group dirname  #递归修改目录下所有内容
```
3. **chgrp** 仅修改所属组
```bash
chgrp group filename
chgrp -R group dir
```
4. **chmod** 修改权限
- 符号模式：`u/g/o/a` ±/= `r/w/x`
```bash
chmod u+x file      #所有者增加执行
chmod go‑w file     #组、其他人去掉写权限
chmod a=r file      #全部人设置只读
```
- 数字模式：`chmod 755 file`

> 💡易错：chmod的`‑R`递归，修改目录权限会连带内部所有文件，线上谨慎使用；密钥文件建议设置600，防止其他用户读取。

### 1.5 特殊权限SUID、SGID、Sticky
> 特殊权限存在安全风险，非必要不开启

|特殊位|数字值|命令设置|作用|
|---|---|---|---|
|SUID|4|`chmod u+s file`|文件执行时，使用**文件所有者身份**运行（如passwd命令），仅对二进制程序生效，不要给脚本设置SUID|
|SGID|2|`chmod g+s dir`|目录下新建文件自动继承目录所属组，多用于协作共享目录|
|Sticky粘滞位|1|`chmod +t dir`|目录内文件，**只有文件属主才能删除/改名**；典型：`/tmp`目录|

### 1.6 ACL与扩展属性
传统ugo权限粒度不足时使用：
1. ACL访问控制列表：可以给指定用户单独设置权限
    - `setfacl` 设置acl规则
    - `getfacl` 查看acl规则
2. 扩展属性：键‑值元数据
    - `setfattr` 设置
    - `getfattr` 获取

### 1.7 实战运维建议
1. **最小权限原则**：只给必需身份开放必要权限；目录谨慎组合w+x；密钥配置建议ACL+加密双重防护；修改权限先测试，支持回滚。
2. **定期安全审计**
    - find扫描全局可写、无属主文件
    - 检查系统SUID/SGID文件，回收多余特殊权限
    - 使用`auditd`监控权限变更、异常访问

## 第二部分 vi编辑器：从入门到精通
### 2.1 vi起源与特点
- 1976 Bill Joy开发，BSD UNIX诞生，Linux系统**默认标配编辑器**，全部操作依靠键盘，不需要鼠标。
- **限制**：可视窗口20行；最大25000行；单行最多1024字符。
- **优势**：启动极快，占用资源极低；所有服务器都自带；适合远程低带宽服务器环境；支持脚本自动化编辑。

### 2.2 核心：双模式机制
> ⚠️ vi最大坑点：模式混淆！同一个按键在不同模式含义完全不同。

|模式|作用|切换方式|
|---|---|---|
|**命令模式**|输入当做指令：移动光标、复制、删除、保存、退出|任意模式按`Esc`回到命令模式|
|**编辑(插入)模式**|键盘输入直接写入文本|命令模式输入 i/a/o/I/A/O进入|

✅铁律：**搞不清楚当前状态，直接按Esc，回到命令模式**。

### 2.3 六把钥匙：命令模式进入插入模式
|按键|功能|
|---|---|
|`i`|光标**左侧**插入文本，局部修改|
|`I`|跳到**行首（非空字符）**插入，写注释、缩进|
|`a`|光标**右侧**追加文本|
|`A`|跳到**行末尾**追加（最高频）|
|`o`|**当前行下方新建空行**并进入编辑|
|`O`|**当前行上方新建空行**并进入编辑|

> 💡易错点：在编辑模式下直接输入命令会把命令当做文本写入文件；操作前确认处于命令模式。

### 2.4 vi标准高效操作流程
1. 起点：**命令模式**
2. 移动光标 h j k l（左、下、上、右）
3. 选择插入入口 i/a/o/I/A/O
4. 输入编辑文本
5. 按 **Esc 返回命令模式**

### 2.5 vi效率思考
1. 核心思想：**模式分离**，命令与文本输入分开。
2. 80/20法则：掌握模式切换，就掌握vi80%能力；搭配删除、撤销、保存即可完成绝大多数工作。
3. 使用习惯：每一次编辑结束，习惯性Esc切回命令模式，避免模式错乱。

> 📌常见新手踩坑：
> 1. 进入vi直接打字，一堆乱字符写到文档里：没有切换插入模式；
> 2. 不知道怎么退出编辑：记住Esc回到命令模式，`:q`退出；
> 3. 分不清o和O，上下搞反；A在行尾追加，不要移动光标到行尾再a。

## 速查备忘录
### Linux权限速记
1. 文件x权限代表可执行；目录x权限代表可进入访问。
2. SUID不要给shell脚本；Sticky位保护共享目录防止误删他人文件。
3. 目录r≠可以访问文件；r+x同时具备，才能正常浏览目录内容。

### vi速记
- Esc永远回到命令模式；
- i/I：光标/行首插入；a/A：光标后/行尾追加；o/O下/上新建行。
